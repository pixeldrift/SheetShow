# Working rules

- **American spelling everywhere**: code, comments, UI text, help, README and commit messages. Use "color", "center", "gray", "neighbor", "behavior", "normalize" and so on. Never mix in British spellings.
- **Reply style**: do not start a reply with "Now". If a step order needs signaling, say "First," instead.
- **Words**: use the names in `docs/terminology.md` for every concept (record, field, template, object, card, sheet, page template, packet…), in the interface, help, and comments.
- **Mobile first**: every feature must work well on a phone before it is polished for desktop. Design for a narrow touch screen (about 390 px wide, thumb reach, 44 px touch targets, no hover-only actions), then let wider screens add space and shortcuts. Test at phone width first.
